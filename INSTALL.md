# Установка

## Загрузка репозитория
Чтобы установить этот репозиторий и запускать ноутбуки Jupyter на своей машине, сначала понадобится git — возможно, он у вас уже есть. Чтобы проверить, откройте терминал и введите `git`. Если git нет, его можно скачать с [git-scm.com](https://git-scm.com/).

Затем клонируйте репозиторий: откройте терминал и введите следующие команды (не вводите `$` в начале каждой строки — это лишь соглашение, показывающее, что это приглашение терминала, а не что-то другое, например код на Python):

    $ cd $HOME  # или любой другой рабочий каталог, который вам удобен
    $ git clone https://github.com/ageron/handson-ml2.git
    $ cd handson-ml2

Если вы не хотите устанавливать git, можно вместо этого скачать [master.zip](https://github.com/ageron/handson-ml2/archive/master.zip), распаковать его, переименовать получившийся каталог в `handson-ml2` и переместить его в свой рабочий каталог.

## Установка Anaconda
Затем понадобятся Python 3 и набор библиотек Python. Проще всего установить их, [скачав и установив Anaconda](https://www.anaconda.com/distribution/) — отличный кроссплатформенный дистрибутив Python для научных вычислений. В него входит множество научных библиотек, включая NumPy, Pandas, Matplotlib, Scikit-Learn и многие другие, поэтому установка довольно объёмная. Если вы предпочитаете более лёгкий дистрибутив Anaconda, можно [установить Miniconda](https://docs.conda.io/en/latest/miniconda.html), который содержит лишь самый минимум для работы менеджера пакетов `conda`. Устанавливайте последнюю доступную версию Anaconda (или Miniconda).

При установке на MacOSX и Linux вас спросят, инициализировать ли Anaconda командой `conda init`: соглашайтесь, поскольку это обновит скрипт вашей оболочки, чтобы `conda` была доступна каждый раз при открытии терминала. После установки нужно закрыть терминал и открыть новый, чтобы изменения вступили в силу.

При установке в Windows вас спросят, должен ли установщик обновить переменную окружения `PATH`. Делать этого не рекомендуется, поскольку это может мешать другим программам. Вместо этого после установки открывайте меню «Пуск» и запускайте Anaconda Shell всякий раз, когда хотите использовать Anaconda.

После установки Anaconda (или Miniconda) выполните следующую команду, чтобы обновить менеджер пакетов `conda` до последней версии:

    $ conda update -n base -c defaults conda

> **Примечание**: если по какой-то причине Anaconda вам не нравится, можно установить Python 3 и вручную установить нужные библиотеки с помощью pip (это не рекомендуется, если только вы не знаете точно, что делаете). Я рекомендую использовать Python 3.8, поскольку некоторые библиотеки пока не поддерживают Python 3.9 или 3.10.


## Установка драйвера GPU и библиотек
Если у вас есть видеокарта, совместимая с TensorFlow (карта NVidia с Compute Capability ≥ 3.5), и вы хотите, чтобы TensorFlow её использовал, скачайте последнюю версию драйвера для вашей карты с [nvidia.com](https://www.nvidia.com/Download/index.aspx?lang=en-us) и установите его. Также понадобятся библиотеки NVidia CUDA и cuDNN, но хорошая новость в том, что они установятся автоматически при установке пакета tensorflow-gpu из Anaconda. Однако если вы не используете Anaconda, установить их придётся вручную. Если возникнут трудности, подробнее см. [инструкции по установке для GPU](https://tensorflow.org/install/gpu) от TensorFlow.

## Создание окружения `tf2`
Затем убедитесь, что находитесь в каталоге `handson-ml2`, и выполните следующую команду. Она создаст новое окружение `conda`, содержащее все библиотеки, нужные для запуска всех ноутбуков (по умолчанию окружение будет называться `tf2`, но можно выбрать другое имя с помощью опции `-n`):

    $ conda env create -f environment.yml

Затем активируйте новое окружение:

    $ conda activate tf2


## Запуск Jupyter
Почти готово! Осталось лишь зарегистрировать окружение conda `tf2` в Jupyter. Ноутбуки этого проекта по умолчанию используют окружение с именем `python3`, поэтому лучше зарегистрировать окружение под именем `python3` (если вы предпочитаете другое имя, придётся выбирать его в меню Jupyter «Kernel > Change kernel...» каждый раз при открытии ноутбука):

    $ python3 -m ipykernel install --user --name=python3

Вот и всё! Теперь можно запустить Jupyter так:

    $ jupyter notebook

Должен открыться браузер, и вы увидите древовидное представление Jupyter с содержимым текущего каталога. Если браузер не открылся автоматически, перейдите по адресу [localhost:8888](http://localhost:8888/tree). Чтобы начать, щёлкните по `index.ipynb`.

Поздравляем! Вы готовы изучать машинное обучение на практике!

Закончив работу с Jupyter, его можно закрыть, нажав Ctrl-C в окне терминала, где он был запущен. Каждый раз, когда захотите поработать над этим проектом, нужно будет открыть терминал и выполнить:

    $ cd $HOME # или тот рабочий каталог, который вы выбрали ранее
    $ cd handson-ml2
    $ conda activate tf2
    $ jupyter notebook

## Обновление проекта и его библиотек
Я регулярно обновляю ноутбуки, чтобы исправлять проблемы и добавлять поддержку новых библиотек. Поэтому обязательно регулярно обновляйте этот проект.

Для этого откройте терминал и выполните:

    $ cd $HOME # или тот рабочий каталог, который вы выбрали ранее
    $ cd handson-ml2 # переходим в каталог этого проекта
    $ git pull

Если возникнет ошибка, вероятно, это потому, что вы изменили какой-то ноутбук. В этом случае перед выполнением `git pull` нужно сначала зафиксировать (commit) свои изменения. Я рекомендую делать это в собственной ветке, иначе могут возникнуть конфликты:

    $ git checkout -b my_branch # при желании можно использовать другое имя ветки
    $ git add -u
    $ git commit -m "describe your changes here"
    $ git checkout master
    $ git pull

Затем обновим библиотеки. Сначала обновим саму `conda`:

    $ conda update -c defaults -n base conda

Затем удалим окружение `tf2` этого проекта:

    $ conda activate base
    $ conda env remove -n tf2

И создадим окружение заново:

    $ conda env create -f environment.yml

Наконец, снова активируем окружение и запустим Jupyter:

    $ conda activate tf2
    $ jupyter notebook
