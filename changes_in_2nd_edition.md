# Изменения во втором издании
У второго издания шесть основных целей:

1. Охватить дополнительные темы машинного обучения: дополнительные методы обучения без учителя (включая кластеризацию, обнаружение аномалий, оценку плотности и модели смесей), дополнительные методы обучения глубоких сетей (включая самонормализующиеся сети), дополнительные методы компьютерного зрения (включая Xception, SENet, обнаружение объектов с помощью YOLO и семантическую сегментацию с помощью R-CNN), обработку последовательностей с помощью CNN (включая WaveNet), обработку естественного языка с помощью RNN, CNN и трансформеров, генеративно-состязательные сети.

## Переход с TF 1 на TF 2
Переход с TensorFlow 1.x на 2.0 похож на переход с Python 2 на 3. Первое, что нужно сделать, — выдохнуть. Не торопитесь. TensorFlow 1.x ещё какое-то время будет существовать, время у вас есть.

* Начните с обновления до последней версии TensorFlow 1.x (к моменту, когда вы это читаете, вероятно, это будет 1.15).
* Переведите как можно больше кода на высокоуровневые API: tf.keras или Estimators API. Estimators API будет работать и в TF 2.0, но отныне лучше отдавать предпочтение Keras, поскольку команда TF объявила Keras предпочтительным вариантом и, скорее всего, будет прилагать больше усилий к улучшению Keras API. Также лучше использовать слои предобработки Keras (см. главу 13), а не `tf.feature_columns`.
* Если ваш код использует только высокоуровневые API, перевести его будет легко, поскольку он должен работать одинаково и в последнем выпуске TF 1.x, и в TF 2.0.
* Избавьтесь от любого использования `tf.contrib`, поскольку в TF 2.0 его не будет. Одни его части перенесены в основной API, другие — в отдельные проекты, а третьи не поддерживались и были просто удалены. При необходимости установите соответствующие библиотеки или (в крайнем случае) скопируйте часть устаревшего кода `tf.contrib` в свой проект.
* Пишите как можно больше тестов — так переход будет проще и безопаснее.
* Код для TF 1.x можно запускать в TF 2.0, начав программу с `import tensorflow.compat.v1 as tf` и `tf.disable_v2_behavior()`.
* Когда будете готовы к переходу, можно запустить [скрипт обновления](https://www.tensorflow.org/beta/guide/upgrade) `tf_upgrade_v2`.

Подробнее о переходе см. [руководство по миграции](https://www.tensorflow.org/beta/guide/migration_guide) от TensorFlow.
